We use a small vocabulary across the kit. An entry is a single Markdown file in the content folder. Front matter is the block between the opening and closing fences at the top of the file. The manifest is the generated index that the site build consumes. A collection is any grouping of entries that shares a layout. When in doubt, prefer plain Markdown and let the build do the rest; the build is deliberately strict about the manifest so that downstream consumers never have to guess at its shape.
