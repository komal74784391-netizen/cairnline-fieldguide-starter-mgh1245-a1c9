This starter kit gives you everything you need to launch a content-driven field guide: a tiny static site, a Markdown-first content folder, and a build step that keeps the site index in sync. Every article you publish lives in site/content as a Markdown file. The build reads the front matter, builds an index, and regenerates the content manifest so the navigation and search stay accurate without any manual bookkeeping. If you are new here, start with this post, then read the authoring guide before you write your first entry so your front matter matches what the build expects.
